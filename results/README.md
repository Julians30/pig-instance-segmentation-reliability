# Recorded experiment outputs and provenance

These are **original compact reports and figures**, recovered from the author-generated ZIPs for experiments **31**, **32** and **33**. They are not generated by the GitHub Actions job.

- `reports/CERDOS_31_Training_Report.json`, `CERDOS_31_Protocol.json`: YOLO11 seed audit (2026/27/28).
- `reports/CERDOS_32_Training_Report.json`, `CERDOS_32_Protocol.json`: Mask R-CNN seed audit.
- `reports/CERDOS_33_Informe_Final.json`, `CERDOS_33_Protocolo.json`: complete nine-seed COCO summary, original checkpoint hashes, provenance of reused historical predictions and confirmation of the retrospective analysis.
- `tables/CERDOS_33_global_metrics.csv`: all nine AP measurements (machine-readable, no Excel required).
- `tables/CERDOS_33_per_date_metrics.csv`: all 45 run–date AP values.
- `tables/*.xlsx`: original author-generated tables from the three experiment ZIPs, convenient for manual audit.
- `figures/*.png`: original 600-DPI paper-oriented validation and test plots. Reproducible plot-generation cells reside in notebooks 31–33.

**Missing from this release:** full weight files and full nine COCO prediction JSONs. Original predictions have been retained in the study's Drive folders, but those files are not currently distributed here. Do **not** assert that this repository alone can recompute COCO AP. A verified, rights-compliant prediction artifact release can be added separately.

**Important:** `Predicted_instances` in COCO reports includes very low-confidence candidate detections (typically `conf=0.001`); it is not a count of high-confidence pigs and should not be equated to operational counting output.

The split and SHA-256 lineage is in `reports/CERDOS_33_Protocolo.json` and `../data/README.md`. Original 2026 predictions are reused from Experiment 09, YOLO26 from Experiment 23, and four new seeds from Experiment 33. Model selection was based on validation AP.
